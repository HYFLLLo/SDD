## 六、开发顺序建议

**阶段1：前端 MVP**
1. 完成 P01 → P02 → P03 → P04，全部使用本地 Mock 数据。
2. 验收（用户门禁）：打开页面，确认布局、配色、交互与 Pencil 原型一致。

**阶段2：前端自动验收**
1. ESLint、Prettier、type-check、build 全部通过。
2. Tester 验证关键路径：快速记录、编辑、随机选题、标签管理、删除。

**阶段3：最终用户验收**
1. 完整流程走通，无阻塞性 Bug。
2. 验收（用户门禁）：用户确认 V1 MVP 可交付。
