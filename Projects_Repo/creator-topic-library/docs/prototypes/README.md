# 原型交接说明

## 原型方式
本阶段使用 Pencil 画布绘制，源文件：`creator-topic-library.pen`。同时保留用户保存的 `yuanxing.pen`。

## 页面清单
- P01 选题库主页：顶部栏、筛选栏、卡片列表、视图切换、快速记录、随机选题。
- P02 选题详情抽屉：标题、内容、备注、来源、标签、状态、优先级、保存/删除。
- P03 快速录入弹窗：标题、内容、来源、标签，保存选题。
- P04 标签管理页：标签网格、新建/编辑/删除。

## 关键组件清单
- 顶部栏：应用名、搜索框、视图切换、快速记录、随机选题、标签管理入口。
- 选题卡片：标题、摘要、标签 chip、状态 badge、优先级标记、更新时间。
- 筛选栏：标签筛选、状态筛选、优先级筛选、时间排序、清除筛选。
- 看板视图：按状态分列，卡片拖动推进。
- 详情抽屉、快速录入弹窗、标签管理卡片。

## 交互状态
- 默认、悬停、禁用、空数据、成功提示。
- 随机选题：无候选时显示空状态；有候选时展示选题并支持换一个。
- 删除操作：确认后执行。

## Mock 数据结构
- 选题：id、title、content、notes、source、tag_ids、status、priority、created_at、updated_at。
- 标签：id、name、color、created_at、usage_count。
- 状态：待验证、创作中、已发布、已放弃。
- 优先级：高、中、低。

## 真实 API 位置
- V1 为本地存储，无后端 API。
- 前端服务层保留 `code/message/data` 响应契约，后续可替换为 FastAPI 接口。

## 生产前端要求
- React + TypeScript + Vite。
- 桌面 Web 使用 Ant Design，并按 B1 Design Spec 的暖纸色板定制 token。
- 原型代码与 Pencil 图层不作为生产前端源码。
