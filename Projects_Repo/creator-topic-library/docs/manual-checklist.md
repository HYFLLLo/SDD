# 最终用户验收走查清单

> 使用浏览器打开 `http://127.0.0.1:5175/` 后逐项勾选。建议按顺序执行。

## 启动与页面

- [ ] 页面正常打开，能看到「创作者选题灵感库」。
- [ ] 首页没有报错弹窗、空白页或明显排版错乱。
- [ ] 页面没有 `[Mock]`、调试文字、临时占位提示等残留。

## 快速记录

- [ ] 点击「快速记录」，弹出「快速灵感」窗口。
- [ ] 不填标题直接保存，能看到「标题不能为空」提示。
- [ ] 填写标题、内容后保存，新选题出现在列表中。

## 搜索 / 筛选 / 排序

- [ ] 用刚才的新标题搜索，能找到该选题。
- [ ] 清空搜索，按状态筛选，列表随之变化。
- [ ] 切换排序方式，列表顺序随之变化。
- [ ] 点击「清除」，筛选和排序恢复默认。

## 编辑选题

- [ ] 点击新选题卡片，打开「选题详情」抽屉。
- [ ] 点击「编辑」，修改标题后保存。
- [ ] 保存后抽屉和列表都显示修改后的标题。

## 看板拖动改状态

- [ ] 切到「看板」视图，新选题出现在「待验证」列。
- [ ] 将新选题拖动到「创作中」列。
- [ ] 拖动后选题停在「创作中」列，状态标记同步变化。

## 随机选题

- [ ] 恢复筛选后点击「随机选题」，弹窗能显示一个候选选题。
- [ ] 点击「换一个」，会切换候选。
- [ ] 将状态筛选改为「已发布」后再点「随机选题」，能看到空池提示。

## 标签管理

- [ ] 进入「标签管理」页，能看到标签列表。
- [ ] 点击「新建标签」，填写名称并保存，新标签出现。
- [ ] 点击新标签的「编辑」，改名后保存，名称同步更新。
- [ ] 点击该标签的「删除」，确认后标签消失。

## 删除选题

- [ ] 返回首页，搜索已编辑的新选题。
- [ ] 点击该选题卡片上的「删除」，确认后选题消失。
- [ ] 再次搜索该标题，显示“没有符合条件的选题”。

## 刷新后持久化

- [ ] 完成编辑、状态拖动、标签增删改等操作后刷新浏览器。
- [ ] 刷新后，之前的编辑结果、状态变化、标签变化仍保持。
- [ ] 删除选题后再刷新，被删除的选题不会重新出现。

## 收尾

- [ ] 全过程没有阻塞性错误、打不开的页面或显示不全的文本。
- [ ] 结束后在运行窗口按 `Ctrl + C` 停止本地服务。
