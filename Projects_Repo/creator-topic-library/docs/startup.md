# 本地启动说明

本应用是纯前端应用，数据保存在浏览器本地。按下面三步即可在自己电脑上打开。

## 准备

- 需要已安装 Node.js（建议 20.19 或更新版本，本项目验证环境为 Node.js 24）。
- 以下命令均在项目目录中的 `frontend` 文件夹下执行。

## 第一步：安装依赖

```bash
cd frontend
npm install
```

如果网络较慢，请保持窗口开启，直到出现命令提示符。

## 第二步：启动

日常验收请使用 5175 端口：

```bash
cd frontend
npm run dev -- --host 127.0.0.1 --port 5175
```

看到 `Local: http://127.0.0.1:5175/` 后，打开浏览器访问：

```text
http://127.0.0.1:5175/
```

停止应用：在运行窗口按 `Ctrl + C`。

## 第三步：构建

需要生成可部署的静态文件时执行：

```bash
cd frontend
npm run build
```

构建成功后，产物在 `frontend/dist` 文件夹中，可交给任意静态站点托管。

## 端口约定

- `5199`：自动开发 / 自动测试使用。
- `5175`：用户门禁验收使用，推荐手动打开此端口。
- 当前 V1 无后端，不启动后端端口；`8099` / `8003` 仅作为后续版本的预留约定。

## 浏览器兼容

- 推荐桌面版 Chrome 或 Edge 最新版本。
- 可支持近期版本 Firefox、Safari。
- 不建议使用浏览器的无痕/隐私模式验收“刷新后数据保持”，因为关闭窗口可能清理本地数据。
