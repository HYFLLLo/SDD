# 变更记录

## 未发布 — UIUX 方案 B「柔和工业」 + M1 项目上下文 + M2 首屏收敛 + M3 视觉收口

### M3 视觉收口
- 内联样式 335 → 11 处（剩 11 处全部含动态值：进度条百分比、
  折叠态 `display:${...}`、选中行高亮）；313 处逐条等价迁移到 72 个工具类。
  这是"按钮比别人高""文字出框"这类点状缺陷的共同根因：没有组件约束时，
  每一处内联样式都是一次独立决策。
- 工具类统一写成 `.u-x.u-x`（specificity 0,2,0），用来覆盖 `.card h3`
  这类 (0,1,1) 的组件规则，仍然禁用 `!important`（全站仅 reduced-motion 2 处）。
  实测：写成单类时 `.card h3` 的 margin-bottom 会压过 `.u-m0`，
  行高从 28px 变 35px，配置页整体下移 7px。
- 新增几何对拍工具 `tools/audit/ui_geometry.py`：13 条路由 × 4 宽度，
  逐元素记录盒子与 43 项计算样式。迁移前后 **计算样式变化 0 处**，
  证明重构零视觉副作用。该工具会在采样前等 DOM 稳定，避免截到半渲染页面。
- 空态全覆盖：业务空态一律走 `emptyState()`，且必须带下一步。
  支持两种动作——跨页跳转（`href`）与聚焦/触发页内控件
  （`data-focus` + 事件委托，仍然满足 CSP 无内联事件）。
  共改 14 处：项目、图片集、提示词、运行记录（首页 / 运行页）、迭代任务、
  模板、历史对话、真值任务、评估记录（两处）、人工矩形框。
- 顺带修掉 3 处引用不存在令牌的失效声明：`var(--muted)` 2 处（聊天等待提示
  颜色回落到正文色）、`var(--bg2)` 1 处（迭代分组头改用 `--surface-2`，
  与 hover 同档）。这类拼写错误在 CSS 里不会报错，只会静默失效。
- 门禁：`INLINE_STYLE_BASELINE` 335 → 11；新增两条测试锁住
  「空态必须有下一步」「工具类必须自叠且不使用 !important」。

- 新增 `--primary-text`：品牌蓝压在 `--primary-soft` 上只有 4.29:1，
  浅色底叠浅色底的文字改用更深一档（5.89:1）。标签、提示条、图标、
  目录当前项、待办步骤序号均随之切换。
- 顶栏浅色化为白底 + 细分割线，暗色保持深底；导航项改为固定 32px 高，
  与下拉触发器严格等高。

## 0.2.0 — 2026-11-06

工程增强（P3）：单实例、结构化日志、版本元信息、路径健壮性与持续集成。

### 新增
- 单实例互斥：`app/instance_lock.py`，基于文件字节区独占锁；端口占用不再被误判为「本平台已运行」，第二实例直接复用已运行地址并打印端口。进程崩溃留下的陈旧锁会按 PID 存活检测自动接管。
- 结构化日志：`app/applog.py` 以 JSON Lines 写入 `workspace/logs/app.log`（2MB × 3 轮转）。请求日志只记方法、路径、状态码与耗时；异常栈与事件字段统一脱敏 `sk-*`。
- 版本与构建信息：`app/meta.py` + `GET /api/version`，返回版本、构建时间、提交号、Python 版本、运行形态（源码/打包）。帮助页显示版本行。
- 路径健壮性回归：`tests/test_paths.py` 覆盖中文、含空格与超过 260 字符的嵌套路径。
- 持续集成：`.github/workflows/ci.yml`，Windows 上跑 pytest（3.11/3.12），Python 3.8 跑字节码对拍。

### 变更
- 启动失败时保留错误信息并等待用户确认，不再窗口一闪而过。
- 请求日志降噪规则：静态资源与高频轮询默认不落盘，慢请求与错误仍保留。

### 修复
- 第二实例复用提示中持锁 PID 为空。
- 日志器在切换工作区后仍写旧目录。
- 新手引导步骤切换滞后：改为同步渲染文案、复用引导 DOM、以 `translate3d` 定位，
  目标查找从固定 1.5–4.5s 等待改为 50/90ms 短轮询（预算 800/2500ms），
  点击到标题更新的实测耗时由 161–1729ms 降到 1–2ms。
- 新手引导第 2 步在站点较多时气泡被挤出视口、页面标题被滚出屏幕：
  目标高于可视区时改为按卡片/页头锚点顶部对齐，气泡优先占位、高亮收口，
  常见窗口高度下气泡与高亮均完整可见且互不遮挡。
- 改完前端后刷新仍看到旧界面：静态资源补 `no-cache, must-revalidate`，
  并给 `app.js` / `style.css` 的 URL 加内容指纹版本号，彻底躲开浏览器旧缓存。
- 新手引导第 2 步改为只高亮单个站点卡片（原先高亮整块列表，站点一多就只能挤在角落）。
- 新手引导气泡支持按住拖动，拖动后位置由用户保持，滚动与缩放不再抢回。
- 新手引导第 3–7 步高亮框与目标错位：原实现为了让气泡有地方放，会把高亮框
  往上撑高或往下收口，导致框线切掉「提示词生成」标题、第 6 步框落在「启动裁判」
  按钮上方 60px 的空块。现在高亮框严格等于「目标 ∩ 可视区」，气泡单独择位
  （下 → 右 → 左 → 上，都放不下时限高内滚），不再改框。
- 新手引导第 3–7 步仍有操作滞后：目标查找里「先等 400ms 再回退到创建入口」的
  探测窗口已移除（实测目标 DOM 30–80ms 就绪），框到位耗时从 530–560ms 降到 30–80ms；
  同时切步骤不再先清空高亮、把气泡闪回屏幕中央，避免「框晚到 + 气泡跳一下」。
- 新手引导第 5 步（人工审核）在空工作区没有任何可指目标：补 `#r-list` 作为
  空态锚点，不再退回全屏压暗居中。
- 主题按钮在深色系统下要连点两下才变亮：原先是 auto → 亮 → 暗 → auto 三态循环，
  当前是「暗」时点一下先回到 auto，而系统本身是深色，auto 看起来仍是暗的，
  视觉上等于没反应。改为「点一下必定翻转亮/暗」；默认仍跟随系统，
  点过之后存显式选择，并在 auto 下监听系统主题变化刷新图标与提示。
- 顶栏「工具」比其它导航项高一截：下拉触发器是行内元素，盒子按基线对齐，
  比兄弟链接整体上移 5px（实测 6–36 vs 11–41）。改为块级后与其它项完全齐平。
- 图片集详情的「把当前筛选图片批量分组」按钮文字出框、比同排下拉框矮：
  包装 div 被 `.row > * { min-width:120px }` 压成 120px，而按钮内容需 158px，
  横向溢出卡片 22px；按钮又用了 `.btn.small`，只有 29px 高。该行改用
  `batch-row` 布局，按钮不压缩、与下拉框同为 38px，窄屏自动换行。
- 帮助页目录与正文耦合：目录原本是正文里的一节，往下滚就消失，长文档里基本没法用。
  现在目录抽成正文左侧 232px 常驻栏（`position: sticky`），正文独立滚动；
  16 个章节可点击跳转，跳转用 `window.scrollTo` 计算位置、不改 `location.hash`
  （这个 SPA 用 hash 路由，改它会整页重渲染），并随滚动高亮当前章节。
  900px 及以下仍保留左侧栏，860px 以下降级为顶栏下的常驻横条，不会再滚走。
  顺带补 `onPageLeave`/`runPageCleanups`：路由切走时摘掉页面级 window 监听，
  避免帮助页的滚动监听在切换页面后堆积。
- 窗口宽度 900px 时全站出现 51px 横向滚动条：`.theme-toggle` 是固定宽度的
  非收缩项，`.topbar nav` 缺少 `min-width: 0`，导航溢出把按钮挤出容器。
  给 nav 补 `min-width: 0`、给主题按钮补 `flex: 0 0 auto`，900px 下
  `scrollWidth == clientWidth == 900`。
- 帮助页正文排版过于扁平：整章被塞进一个 `white-space: pre-wrap` 的 `div`，
  术语表看不出是表格、步骤和嵌套列表只能靠缩进区分、JSON 示例没有等宽底。
  现改为按文档结构解析成语义块再渲染：术语表渲染成真正的 `table`（表头 + 术语/说明两列），
  步骤渲染成带序号方块的列表且支持子步骤嵌套，`- ` 渲染成列表，JSON 示例渲染成等宽代码块
  并按 JSON 语法着色，`Q:/A:` 渲染成问答卡片，`--- 小节 ---` 渲染成正文小标题，
  字段名/文件名/路径做等宽高亮。16 章共生成 27 组步骤、47 个列表、2 个代码块、
  19 个问答、2 张术语表（8 + 19 行），正文段落改回自动换行。
- 浅色模式下卡片没有底色、术语表没有分隔线：`:root` 里一批设计令牌被写成了自引用
  （`--surface-2: var(--surface-2)`、`--primary-soft: var(--primary-soft)` 等），
  变量解析为空值；`--panel` 更是从未定义，`.card` 的 `background: var(--panel)`
  一直是无色。已补齐全部具体色值，并给暗色的两处变量块补上 `--panel`。
