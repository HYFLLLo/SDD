设计假设 Assumptions（理解错了早改比晚改便宜 100 倍）

  • A1：起手题词用手写体呈现，强化"题词"感；人画署名暖色，AI 续署名冷灰蓝
  • A2：P04 进度条是签名锚点——手绘虚线节点链，当前节点陶土橙脉冲
  • A3：画布偏直角(4px)，卡片圆角(12px)，区分"纸"与"卡"
  • A4：实时围观只展示当前作画者的画布，不展示历史笔迹回放
  • A5：投票三维度（最跑偏/最佳画/最佳描述）合并进 P07 回放页底部
  • A6：游客可浏览广场和作品，创建/加入/投票需登录

关键用户路径 Key Flow

  • 主路径（创建接力）：P09 登录 → P01 广场 → P02 创建链 → P04 大厅 → P05 接力作画 → 提交回 P04 → 链完成 → P07 回放+投票 → P06 作品分享
  • 加入路径：P01 广场 → P03 加入(房间码) → P04 大厅 → P05 接力 → …
  • 围观路径：P04 大厅实时围观画布（WebSocket 笔迹）
  • AI 补位路径：P04 节点 24h 超时 → AI 自动续链（标注 AI 续）→ 推进下一节点
